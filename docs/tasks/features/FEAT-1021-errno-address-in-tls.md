## 概要

ランタイムは `errno` を読み書きするたびに C ライブラリの `__errno_location` を呼ぶ。HTTP サーバの 1 要求では、空とわかっている
受信が `EAGAIN` を書き、Std.Net の `recvOn` が `cirka_errno` で読む。呼び出しそのものは数命令だが、`__errno_location` は C ライブラリの
別のページにあり、システムコールの後でキャッシュも TLB も冷えている (要求ごとに実行するコードのページは 12、Rust は 7)。

`errno` のアドレスはスレッドの間は変わらないので、スレッドごとに最初の使用で 1 度だけ聞いて TLS ブロックに置き、以後は
ブロックからの読み込みだけで読み書きする。受信が使う TLS ブロックの欄 (実行中のループ・`errno` のアドレス・受信のバッファ) を
同じキャッシュラインに並べる。
