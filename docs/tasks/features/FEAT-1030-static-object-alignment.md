## 概要

静的なオブジェクト (文字列リテラル・静的な大域変数) と CAF は 8 バイトに揃えて置いていた。16 バイトのオブジェクト (ヘッダと
フィールド 1 つ、ヘッダと長さだけの空文字列) は、番地が 56 mod 64 のとき 64 バイトのキャッシュラインの境界をまたぎ、1 つの
オブジェクトを読むのに 2 本のラインに触れる。リテラルも同じで、どこに置かれるかはリンクの結果次第である (HTTP サーバでは 1 要求で
実行ファイルのデータのラインに 8.0 本触れる)。

オブジェクトの大きさを収める最小の 2 の冪 (8〜64 バイト) に揃える。64 バイト以下のオブジェクトはどこに置かれても 1 本のラインに
収まり、それより大きいものは最少の本数にまたがる。CAF (サンクのヘッダとスタブの 16 バイト) は 16 バイトに揃える。引数のない
構築子 (ヘッダだけの 8 バイト) は 8 バイトのまま。
