## メモ

- 実装: `crates/achc-desugar`。型付き AST (FEAT-0103) を共通 Core に変換し、Core Lint を通す (失敗は ICE)。
- 表現: `Int` / `Char` / `Double` は `I#` / `C#` / `D#` で箱詰め、`IO a` は `Unit# -> a` (CirkaLang と同じ世界トークン方式)。
  組み込み構文は `List` (`Nil` / `Cons`)・`Unit`・`TupleN`、それ以外のデータ型は修飾付きの Haskell 名のまま。
  文字列リテラルは `prim$unpack` で UTF-8 の `Bytes` から遅延リストに展開する。
- プリミティブ: `foreign import prim "p"` は `src/prims.core` の Core 定義 `prim$p` に束縛する。宣言された型と
  プリミティブの Core 型が一致しなければ E0607。未使用のプリミティブと extern は脱糖後に取り除く。
- パターン照合: Wadler の列ごとのマッチコンパイラ (変数規則・構築子規則・混合規則)。整数・文字リテラルは
  一度だけ箱を開けて `Int#` で分岐、`Double` リテラルは比較の連鎖、`!p` は `case` で評価、`~p` は変数ごとの遅延な選択子。
  失敗継続は 1 回しか使わないなら埋め込み、複数回なら遅延 `let` で共有する。後続の節は失敗しうる場合にだけ生成するので、
  生成されなかった節を W0611 (冗長な節)、最後の失敗に到達しうる照合を W0610 (非網羅) として報告する。
  `otherwise` と `True` のガードは常に成功するものとして扱う。
- 型検査器の修正: 再帰しないパターン束縛を `rec` にまとめていたため MIR が循環データとして拒否していた。
  共有する右辺 → 各選択子の順に非再帰の束縛として出力するよう修正。
- 既知の制限: newtype の構築子パターンは `case` になるため、GHC と違って値を評価する (⊥ のときだけ差が出る)。
  再帰的なパターン束縛 (循環データ) は MIR が未対応。
- テスト: `crates/achc-desugar/src/tests.rs` (MIR インタプリタで実行、最適化あり/なしの一致とリーク 0)、
  `tests/achc/desugar/*.hs` (Core スナップショット `.core` と警告 `.warn`)。
