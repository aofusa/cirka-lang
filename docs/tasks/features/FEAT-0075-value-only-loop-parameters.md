# FEAT-0075: ループが読むだけの配列の引数を、入口で値と確かめて反復ごとの force をなくす

- 状態: done
- トラック: 共通基盤
- マイルストーン: M2
- 優先度: P1
- 依存: FEAT-0067, FEAT-0070, FEAT-0073
- 設計: [06-ir.md](../../design/06-ir.md) §3

## 概要

自己末尾呼び出しのループは、引数の配列を毎反復 `force` する。一意に書き込む配列は FEAT-0067 で特殊化したが (`f$u`)、読むだけの配列は対象外なので、反復ごとに種別を読んで比べている。
LLVM は次の反復の引数が `force` の遅い経路の結果と合流する (`phi`) ので、反復をまたいで検査を消せない。

- fannkuch-redux の `copy` は反復あたり命令 9 のうち 4 が読むだけの `src` の検査で、`memcpy` にもならない。
- spectral-norm の内側のループ `mul$go$f1$w$b`、n-body の `energy` など、読むだけのループの多くで同じことが起きている。

`f$u` の仮定を「一意」だけでなく「値である (共有でもよい)」に広げ、`force` される引数は入口で `is_value` で確かめ、`f$u` では `force` を除く。読むだけの引数しかないループも特殊化する。
