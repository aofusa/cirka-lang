# FEAT-0062: 一意性と再利用トークンを MIR の型で区別し、引数に nonnull / noalias / readonly を付ける

## 概要

FEAT-0058 で付けられなかった引数の属性を、MIR に必要な事実を持たせて付ける。

- `nonnull` / `dereferenceable(8)`: MIR の `ptr` には null になりうる再利用トークンが混ざるので、トークンを別の型にする
  (または検証器でトークンが関数の引数・結果にならないことを保証する)。
- `noalias`: 引数が一意 (RC==1 が静的に分かる) であることを MIR に記録する。フロントエンドの一意性・線形性から運ぶ。
- `readonly` / `nocapture`: 借用引数でも呼び出し先が `dup` して保持しうる (RC を書く) ので、今の借用推論だけでは付けられない。
  「dup も保存もしない」引数を解析で求める。
