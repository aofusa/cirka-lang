## メモ

- 所有権は変数ごとの「所有数」(dup で +1、消費で -1) を基本ブロック上で前向きに解析する。借用 (borrowed 引数・`proj`/`array_get` の結果) は元の変数が生きている間だけ使える。
- 再利用トークンのサイズは、`switch` の腕 (単一の先行ブロック) や `proj` から分かる構築子で決める。分からない場合はエラー。
- LType 由来の「dup してはならない」検査は、MIR に LType の情報がないため型検査器 (aCHC H3 / CirkaLang) 側で行う。
- 診断は関数名とブロック名で位置を示す (MIR には命令単位の Span を持たせていない)。
