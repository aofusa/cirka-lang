## メモ

- 実装: `cirka-mir::lower::lower_program` (06-ir.md §3)。出力は dup/drop なしの MIR で、`perceus::run` を続けて適用する。
- 評価規則: 関数・サンクの結果、`case` 束縛、`let!`、正格フィールドは WHNF。関数引数・遅延フィールド・遅延 `let` はサンクでありうるので、値が必要な所で `force` する。非原子的な引数はサンク化 (自由変数を捕捉する持ち上げ関数)。非ボックス値は常に先行評価。
- クロージャ: 値として使うラムダはクロージャ規約 (引数・結果はすべてポインタ。非ボックス値は `$BoxI`/`$BoxF` で箱詰め) の関数へ持ち上げ。`letrec` のラムダはラムダ持ち上げして飽和呼び出しは直接呼び出し。トップレベル関数はネイティブ表現のまま、値として使う時に `$clo` ラッパーを生成。部分適用は `mkclosure`、過剰適用は呼び出し後に `apply`。9 引数以上のラムダは 8 引数ごとに分割。
- トップレベルの非関数は CAF (`global`)。非ボックスの定数は引数なし関数。
- 未対応 (診断を出す): 関数以外の再帰束縛 (循環データ)。
- `cirka-mir` は `.core` を入力に取れる (Lint → 変換 → Perceus)。`CIRKA_DUMP_MIR=1` で MIR を表示。
- テスト: `tests/core/run/` の 5 プログラム (遅延無限リスト `from`/`take`、辞書と高階種、Any/cast・線形資源、クロージャ・letrec・部分/過剰適用、Double/文字列/配列/newtype/CAF/正格フィールド、不完全なパターンでの panic) をインタプリタとネイティブ (debug/release) で実行し、出力・終了コード・確保/解放回数が一致しリーク 0。
- 修正: `reuse::sink_dups` が隣接する dup を無限に入れ替える不具合を修正。
