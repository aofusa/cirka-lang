## 概要

構成した積の結果 (CPR、FEAT-0065) は、葉が 1 つで箱入りの型の結果を分解しない (遅延フィールドはサンクかもしれず、関数がサンクを返してはならないため)。
CirkaLang の借用 (FEAT-0220) で結果が `()` の計算 `Borrow a r ()` は、結果が `(状態, Ur ())` で葉が状態 1 つになるので、
末尾でない位置の呼び出しのたびに組と `Ur` を確保する (挿入ソートの外側のループで 1 回あたり 2 回)。

葉が評価済みと分かる場合 (`let!` の束縛子・case の束縛子・正格な引数) に限って、葉 1 つの結果も worker の戻り値にする。

## 作業内容

- [ ] CPR の形の解析で、葉の式が評価済みかを持つ
- [ ] 葉 1 つで箱入りでも、すべての戻りで評価済みなら分解する
- [ ] 単体テストと実行テスト (確保の回数)

## 受け入れ条件

- [ ] 結果が `()` の借用の計算を末尾でない位置で呼ぶループが確保しない
- [ ] 全ベンチの出力が変わらず、時間が増えない
- [ ] `scripts/ci.sh` が通る
