## メモ

- 実行テストは `tests/mir/run/*.mir` (期待出力 `.stdout`、終了コード `.exitcode`、入力 `.stdin`)、検証器のエラーテストは `tests/mir/fail/`。
- インタプリタはネイティブのランタイムと同じ意味論 (静的オブジェクト・eval/apply・サンクの IND 書き換え・再利用) を持ち、確保/解放/再利用の回数を数える。`run` は 1GiB スタックのスレッドで実行する。
- 利用できる extern はランタイムの I/O 関数 (`cirka_write_*`, `cirka_read_byte`, `cirka_exit`, `cirka_panic_bytes` 等) のみ。
