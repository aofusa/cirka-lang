# BUG-0015: CirkaLang で線形型の値が `Type` の型変数や IO の結果を通じて複製できる

- 状態: done
- 重大度: critical
- 発見箇所: FEAT-0212 の設計中
- 関連: FEAT-0202, FEAT-0212

## 現象

線形型 (`LType`) の値を複製できるプログラムが型検査を通る。利用者定義の `Release` (FEAT-0212) が入ると二重解放になる。

1. 宇宙 `Type` の暗黙の型引数 (`{a : Type}`) がメタ変数の解として線形型に具体化される。

   ```
   dup : {a : Type} -> a -> Pair a a
   dup x = MkPair x x

   main = case dup (mk 3) of        -- mk 3 : Tok (LType)
     MkPair a b => printInt (use a + use b)
   ```

2. 型注釈のないラムダの引数 (多重度 ω) の型が、後から線形型に解ける (`(\x => MkPair x x) (mk 3)`)。
3. `Pair` などの Prelude のデータ型が `Type` の引数しか取れないのに、`MkPair (mk 1) (mk 2)` が通り、`Pair Tok Tok` が共有可能な型として扱われる。
4. (修正中に発見) 線形な値を受け取った部分適用やアクションは、その値を保持するのに型は共有可能 (`Int -> Int`、`IO ()`) なので、何回でも使える。

   ```
   f : (1 t : Tok) -> Int -> Int
   main = let g = f (MkTok 3) in printInt (g 1 + g 2)    -- 同じ Tok を 2 回使う
   ```

   ω の引数に渡す (`twice (useIO (MkTok 3))`) 場合も同じ。
5. (修正中に発見) トップレベルの値は一度だけ評価されて共有されるのに、線形な型の値 (`tok : Tok`)、線形な値を保持する値
   (`f = use (MkTok 1)`)、線形な型のメソッド (`make : a`) を定義できた。トップレベルの `IO` の値 (`act = useIO (MkTok 1)`) は
   2 回実行すると同じ値を 2 回使っていた。

## 再現手順

上のプログラムを `cirka run` すると `6` を出力して終わる (型エラーになるべき)。4 は `9`、5 の `act` は `3` を 2 回出力していた。

## 期待される動作

- `Type` の型変数を線形型で具体化したら E0301。
- 多重度 ω の束縛子の型が後から線形型に解けたら E0301。
- 型引数を取るデータ型は引数の宇宙を伝播する (`Pair Int Int : Type`、`Pair Tok Int` は線形)。
- 線形な値を保持する値は線形 (2 回使うと E0303、ω の位置では E0305)。
- トップレベルの値は線形な値を持てない (E0301 / E0305)。トップレベルの `IO` の値は実行のたびに線形な値を作る。

## 原因

U-Bind の検査 (`check_ubind`) は束縛の時点の型だけを見ていて、メタ変数が後で解けた場合を再検査していなかった。
暗黙の型引数のメタ変数は種 (宇宙) を検査せずに単一化で解かれていた。
データ型のパラメータは `Type` に固定され、線形な型を渡すことを検査していなかった。
使用量の検査は変数の出現だけを数えていて、変数でない線形な値が部分適用やアクションに閉じ込められる場合を見ていなかった。
トップレベルの値には使用量の検査がなかった。

## 修正

- [x] 回帰テストを追加 (`tests/cirkalang/fail/own/` の `type_param_linear` `lambda_binder_linear` `holder_let` `holder_action`
  `holder_arg` `holder_top` `top_linear` `method_linear`、run テスト `v002/linear_params` `v002/raii_io_value`、
  `cirkalang-elab` の単体テスト `holders_are_linear` `resource_free_binders_are_copied`)
- [x] 修正 (spec-v0.0.2.md §5.1〜5.3、ADR-059 / ADR-060)
  - 単一化で解けたメタ変数の宇宙を、型を検査し終えた後に検査する (`shareable` の保留目標。`Type` の型変数と ω の束縛子)。
  - データ型のパラメータは型を書かなければ `LType` を範囲とし、線形性を伝播する (`lin_params`)。`Type ⊑ LType` の部分型は評価器の `sub` で扱う。
  - 変数でない線形な引数を受けた適用で、結果が線形な値を隠しうるものを保持者とし、`let` / `case` を多重度 1 にする (`Cxt::holders`)。
  - トップレベルの値と関数でないメソッドの型が線形なら E0301。保持者は `IO` / `IO1` なら遅延し (`share_top`)、それ以外は E0305。
  - 資源を持たない型の線形な束縛子は複製してよい (伝播によって `(1 r : Result String Int)` のような束縛が増えるため)。

## メモ

- 保持者の判定は、変数でない線形な値を受けた適用の結果だけを見る。保持者を引数として受け取った関数がそれを捨てる場合は、
  終了処理が実行されないリークになる (安全性の違反ではない)。`let` で束縛して使わない場合は W0308 で警告する (FEAT-0212)。
